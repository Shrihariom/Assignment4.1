 # Assignment 4.1 — Student Registration Form

**Objective:**  
To create a student registration form using HTML form elements and different input types.

**Requirements:**
- Visual Studio Code
- Web Browser
- HTML5

**Procedure:**

1. Open the existing project folder in VS Code.
2. Create a new HTML file named `registration.html`.
3. Create a form using the `<form>` tag.
4. Add Full Name, Email, Password, Phone Number and Age fields.
5. Use appropriate input types for each field.
6. Add a proper `<label>` for every input field.
7. Give every input a unique `id` and meaningful `name`.
8. Use the `required` attribute for mandatory fields.
9. Add a Submit button.
10. Save the file and open it in a browser.
11. Test the form by entering sample information.

**HTML Elements Used:**

| Element / Attribute | Purpose |
|---|---|
| `<form>` | Creates a form |
| `<label>` | Defines the input label |
| `<input>` | Accepts user information |
| `type="text"` | Accepts text |
| `type="email"` | Accepts email address |
| `type="password"` | Accepts password |
| `type="tel"` | Accepts phone number |
| `type="number"` | Accepts numerical age |
| `required` | Makes a field mandatory |
| `<button>` | Creates the submit button |

**Result:**  
Successfully created a student registration form with all required input fields and a submit button.

**Conclusion:**  
I learned how to create HTML forms, use different input types, connect labels with inputs and apply basic form validation.
